# Far Reach moves to SDK 0.9.0

The 0.0.10 images-only re-pack was built against a linked SDK. Now that
0.9.0 is on npm (under `next`, while `latest` is still 0.8.1), the repo
pins it exactly, with engine 0.1.99-next.6385c3d0 and format 0.82.3, and
re-proves the pack and the cook entry under that pin before the bulk push.
