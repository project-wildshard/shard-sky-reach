# Far Reach moves to SDK 0.9.0

The 0.0.10 images-only re-pack was built against a linked SDK. Now that
0.9.0 is on npm (under `next`, while `latest` is still 0.8.1), the repo
pins it exactly, with engine 0.1.99-next.6385c3d0 and format 0.82.3, and
re-proves the pack and the cook entry under that pin before the bulk push.

`wildshard migrate` ran the 0.8.0 (MeleeProfile) and 0.9.0 (shard version
header) migrations; neither changed source here, only GUIDE.md and the
`migrated` stamp. It refuses a dirty tree and another lane's untracked
`public/` sits in this checkout, so it ran in a scratch clone and the result
was copied back. The 0.0.10 re-pack changed content after the last hero, so
`wildshard check` refused a stale hero: it was recaptured from `wildshard
dev`, same world and framing. Check passes; the prepared shardfile is 61.5 MB.
