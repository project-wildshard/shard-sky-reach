# Keep every declared image fallback

The native Simulator phone boot revealed the next missing image after
the six baked textures were restored: Pine phone horizon. A census of
all explicit image-mode boot declarations found eleven further omitted
images across Driftwood, Pine and Far Reach. Their authored bytes exist.

Extend the C0 mount lists to include those image alternatives, preserving
all KTX2 paths and every file byte. The engine frozen pins carry the same
immutable producer blobs and check publication before and after build.
