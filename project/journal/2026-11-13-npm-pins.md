# Pins from npm (NPM-PUBLISH NP8)

Engine, the sdk and shard-format now install from npm instead of
github commit specs: engine `0.1.18`, `@wildshard/sharddev` as
`npm:@wildshard/sdk@0.2.12`, `@wildshard/format` as
`npm:@wildshard/shard-format@0.4.9`, the same in `pnpm.overrides`.
They are exact, as SA8 wants a repo's pins to be. sdk 0.2.12 pins
engine 0.1.18 itself, so one engine is installed.

Engine 0.1.18 declares vite, sharp, typescript6 and `@types/three` as
peers, so the `packageExtensions` patch for engine is gone.
`assert-store-layout.mjs` still finds vite, typescript6 and sharp from
engine inside the store. Ring 3's `select-candidate.mjs` still swaps in
github candidates by override, which is its job.
