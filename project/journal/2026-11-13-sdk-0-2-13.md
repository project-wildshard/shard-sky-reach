# Sky Reach on sdk 0.2.13 (S12f upload)

SHARD-SIZE S12f queued a Sky Reach upload, and plain
`wildshard prepare` on sdk 0.2.12 timed out: the preview served the
candidate's discovery from the wrong place, so its boot stopped at
"Discovery of far-reach answered 404". sdk 0.2.13 (sharddev 5f7492b)
serves each mount from where cook.json keeps it, so Far Reach now
prepares on the npm install alone.

`wildshard update --pins=0.2.13` moved the sdk and shard-format
0.4.10, installed them and ran check green (build 42.9 s, 33.42 MB
download). Next: prepare, pack and upload to staging.
